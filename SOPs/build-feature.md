# SOP — Build Feature (General)

**Status**: Reference pipeline  
**Orchestration**: LoopForge-compatible

## Stages

1. **Intent Clarification** (Karpathy + Superpowers)
2. **Design** → Plannotator review → sign-off
3. **Implementation Plan** (TDD-oriented, junior-friendly)
4. **Execution** under Superpowers + domain skills as required
5. **Verification** (tests + Chrome DevTools / BrowserAct when UI or live systems involved)
6. **Attestation** via an-nexus for significant deliverables
7. **Retrospective** captured by LoopForge
