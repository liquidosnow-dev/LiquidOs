# Karpathy Guidelines Skill

This skill is permanent context for every LiquidOs agent session.

## Principles

1. **Think Before Coding** — State assumptions, surface trade-offs, ask instead of guessing, push back on complexity.
2. **Simplicity First** — Minimum viable code. No speculative features or premature abstractions.
3. **Surgical Changes** — Touch only what was requested. Clean up only your own mess.
4. **Goal-Driven Execution** — Convert requests into verifiable success criteria and loop against them.

Full details: `Methodology/KARPATHY.md` and `Methodology/LIQUIDOS_DEVELOPMENT_CONTRACT.md`.

## When to Apply

Always. This skill does not deactivate.
