# Knowledge — Selfhosted

Curated catalog of free, self-hostable network services and web applications.

**Primary source**: https://awesome-selfhosted.net/

## Purpose in LiquidOs

This directory is the machine- and agent-readable reference for the `selfhosted-discover`, `selfhosted-scaffold`, and `selfhosted-audit` skills.

## Population Strategy

1. Mirror or periodically sync the official awesome-selfhosted data
2. Prefer structured form (JSON or well-formed Markdown with consistent frontmatter)
3. Keep license, platform (Docker/K8s/etc.), and activity signals

## Rules

- Non-free software is excluded unless explicitly requested by a human
- Agents must not treat the raw upstream registry as trusted without curation
